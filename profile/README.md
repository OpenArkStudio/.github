OpenArkStudio develops open-source libraries and frameworks for C++ server applications,
including game servers. Our core projects focus on modular services, asynchronous
networking and cross-platform development on Linux, macOS and Windows.

## Choose your starting point

| Project | What it provides | Start here |
| :--- | :--- | :--- |
| **[ark](https://github.com/OpenArkStudio/ark)** | A C++20 application framework with plugins, module lifecycles, entity data and process communication. | [Quick start](https://openarkstudio.github.io/ark/get-started/quick-start/) · [Examples](https://github.com/OpenArkStudio/ark/tree/main/examples) |
| **[arknet](https://github.com/OpenArkStudio/arknet)** | A C++20 header-only library for TCP, UDP, HTTP, WebSocket, reliable UDP and native MySQL/Redis clients, with optional secure transports. | [Installation](https://openarkstudio.github.io/arknet/get-started/installation/) · [Examples](https://github.com/OpenArkStudio/arknet/tree/main/examples) |

Use **ark** when you need an application framework to organize services and data.
Use **arknet** when you need networking or database clients in your own application.
ark uses arknet for networking; arknet can also be used independently.

## Explore and contribute

- **Learn:** follow the [ark guides](https://openarkstudio.github.io/ark/) or [arknet protocol guides](https://openarkstudio.github.io/arknet/). Both documentation sites are available in English and Chinese.
- **Report a problem:** open an issue in [ark](https://github.com/OpenArkStudio/ark/issues) or [arknet](https://github.com/OpenArkStudio/arknet/issues), with the platform, revision and a reproducible example.
- **Contribute:** improve examples, documentation, tests or implementation. Check the target repository's contributor instructions before opening a pull request.
- **Discuss:** join [Discord](https://discord.gg/GmyBbcv) or start with an issue in the relevant repository.
