# OpenArkStudio visual assets

[简体中文](README_CN.md)

The selected identity combines the cradle symbol with Inter 600 lettering and electric blue / cyan. OpenArkStudio uses one dot, ark uses three modules, and arknet uses linked nodes.

The horizontal lockup uses the selected **symbol emphasis** proportions: hull height 88, lowercase x-height 80, and a visible gap of 40 units. The organization symbol has a 17.6-unit optical lift beside the two-line OpenArk / STUDIO lettering.

![Selected identity](identity-overview.png)

## Files

Replace `{brand}` with `openarkstudio`, `ark` or `arknet`.

| File | Use |
| --- | --- |
| `{brand}-logo-light.svg` | Symbol and lettering on light backgrounds |
| `{brand}-logo-dark.svg` | Symbol and lettering on dark backgrounds |
| `{brand}-logo-mono.svg` | Single-color horizontal lockup |
| `{brand}-icon.svg` | Standalone symbol |
| `{brand}-icon-dark.svg`, `{brand}-icon-mono.svg` | Dark and single-color symbols |
| `{brand}-wordmark-light.svg`, `-dark.svg`, `-mono.svg` | Lettering without a symbol |
| `{brand}-avatar.png` | 512 × 512 transparent PNG |
| `{brand}-social-preview.svg`, `.png` | 1280 × 640 GitHub link-sharing card |
| `identity.json` | Selected proportions, palette and font metadata |

All 27 identity SVGs have transparent backgrounds, accessible titles and outlined lettering. The three sharing-card SVGs use a light background and outlined captions. None require installed fonts or external font requests.

## Colors and placement

- Light backgrounds: blue `#1464F4`, cyan `#06BBDD`, text `#11213B`.
- Dark backgrounds: blue `#508AFF`, cyan `#2CD6EE`, text `#F2F7FF`; preview background `#101D34`.
- Preserve the SVG aspect ratio. In READMEs, set the width and allow the height to follow automatically.
